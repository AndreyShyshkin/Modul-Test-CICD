# Population and Area Sorter

## Опис проєкту
Цей скрипт розроблено для автоматизованого зчитування даних про країни (назва, площа, населення) з текстового файлу та їх подальшого сортування. Проєкт реалізує базові принципи Continuous Integration (CI), включаючи автоматичне тестування та перевірку стилю коду.

## Структура репозиторію
- main.py - головний модуль із логікою парсингу та сортування.
- test_main.py - unit-тести для перевірки коректності функцій.
- data.txt - вхідний файл із даними.
- requirements.txt - перелік залежностей проєкту.
- .github/workflows/ci.yml - конфігурація GitHub Actions.

## Розгортання та запуск
1. Клонуйте репозиторій на локальну машину.
2. Встановіть необхідні залежності:
   pip install -r requirements.txt
3. Запустіть головний скрипт для обробки даних:
   python main.py

## Тестування
Для перевірки працездатності коду та генерації звіту виконайте команду:
pytest --html=report.html
Звіт буде збережено у файлі report.html.
